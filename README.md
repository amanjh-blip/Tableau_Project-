# Airlines Sales Analysis Dashboard

## Project Overview
This project presents an interactive **Airlines Sales Analysis Dashboard** created using Tableau. It analyses sales, profit, quantity, regional performance and sales trends using different visualizations.

## Dataset
- **Dataset Name:** Airline_Sales_Tableau_Dataset
- **Source:** Kaggle
- **Records:** 500
- **Format:** CSV

## Tools Used
- Tableau
- CSV Dataset
- Data Visualization

## Dashboard Visualizations
- KPI Cards – Total Sales, Profit, Quantity and Profit Ratio
- Bar Chart – Sales by Airline/Product
- Line Chart – Sales and Profit Trend
- Map – Regional Sales Performance
- Scatter Plot – Sales vs Profit
- Clustering – Performance Segmentation
- Interactive Filters – Region, Category, Airline/Product and Date

## Calculated Fields
- Total Sales
- Total Profit
- Profit Ratio
- Average Sales

## Files Included
- Tableau Workbook (.twb/.twbx)
- Dataset (.csv)
- Dashboard Screenshot
- README.md

## Conclusion
The dashboard provides an interactive and visual analysis of airline sales performance and helps identify important sales, profit and regional trends.
